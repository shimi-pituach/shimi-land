# מפת הסקילים המרוכזת של הסטודיו — הפקת לאה
ארכיון האושיות · לאה · קודה · 24/10/2026

כל סוכן מתקין את הסקילים האלה בסביבתו (.agents/skills/). הסקילים זהים בין סוכנים — העתקה ישירה של התיקייה.

## 1. ltx-free-clip — קליפ תנועה חינמי מפריים (ZeroGPU)
מרחב Lightricks/ltx-video-distilled דרך gradio_client. מידות מרובעות 768x768 לפריימים מרובעים (מונע חיתוך ראש/רגליים). טיפול מכסה + העלאה לx0.at + באטץ' עם דילוג על קיים. טוקן: /tmp/hf_token בסביבת הסוכן בלבד.

## 2. lea-short-clip — הרכבת שורט ויראלי אנכי (חדש, קודה, 24/10)
השיטה שיצרה את short2_transform (הדוגמה הראשונה: aidoor.shimi.land/gallery/videos/kungfu-lessons/short2_transform.mp4).
מבנה: כרטיס הוק → פריים קאנוני בזום איטי + פס טקסט → קאט חד (ברירת מחדל בשנייה 4.0) לקליפ תנועה בהילוך אטי עם רקע מטושטש → כרטיס CTA עם חתימת קודה. 1080x1920, 25fps, בלי אודיו (מוזיקה טרנדית באפליקציה בלבד).
חוקים מובנים: RTL תקין דרך PIL-raqm בלבד (אסור get_display/reshape — טקסט הפוך), הוק מתאים לשניית הקאט, תיעוד חובה לפי 04_protocol.
הרצה:
```bash
python3 scripts/run.py --frame <פריים.jpg> --motion <קליפ.mp4> --hook "..." --strip1 "..." --strip2 "..." --cta "..." --cta2 "..." --out short.mp4
```
נבדק חי: short2 (טרנספורמציה, קאט אומת 61-spike בשנייה 4.0) וshort3 (פייל-אודיו, בעיטה מסובבת).

## 3. koda-motion-clip — רינדור סטודיו + הרכבה עם כרטיסי כותרת
ציטוט מנועי הסטודיו (grok/seedance), הרכבה עם title/sig. תוקן RTL ב24/10 — כרטיסי כותרת עכשיו תקינים.

## 4. shimi-video-kit — תזמור מוזיקה/סנכרון/סרט אמן
MASTER.md + DOCים בתיקיית shimi-video-kit בכל סביבה. לפרויקטים ארוכים וקליפים מרובי סצנות.
