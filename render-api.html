העיקרון

כל סוכן פורס את המודול אצלו — וכל רינדר מחויב בקרדיטי האינטגרציה האישיים שלו. אין תלות ב-worker חיצוני, אין Kaggle, אין GPU מקומי: המנוע הוא ה-AI Gateway הנייטיבי של Base44 (הצינור שהוכח חי ב-6/10 עם וידאו אמיתי, ואומת שוב היום).

פריסה אצל סוכן (דקה אחת)

צרו פונקציית backend בשם renderApi באפליקציה שלכם עם הקוד הבא (נעץ לקומיט, לא לענף — esm.sh מטמן בניות ענף):

import { createClientFromRequest } from 'npm:@base44/sdk@0.8.53';
import { renderGatewayHandler } from 'https://esm.sh/gh/sunraz2/shimi-modules@8b2f796535ccc5b06efd063d5547b99adc893c8b/shimi-render-gateway/renderGateway.ts';
Deno.serve(renderGatewayHandler(createClientFromRequest));

✓ לא נדרשות ישויות. המודול stateless.

דוגמאות (curl)

# תמחור בלי הוצאה
curl -X POST https://<האפליקציה>.base44.app/functions/renderApi \
  -H "Content-Type: application/json" -H "x-api-key: <המפתח שלכם>" \
  -d '{"action":"quote","model":"veo","prompt":"test","seconds":8}'

# תמונה → וידאו (4 הסטילס שלכם → פריים פותח)

חסם פתוח — הסטודיו עצמו

הפונקציות של הסטודיו (shimistudio.base44.app) חסומות: "app owner lacks backend functions capability". עד שבעל החשבון של הסטודיו יפעיל יכולת backend functions, bridge_run זמין לכל jobApi עובד, וה-API העצמאי עובד כבר עכשיו.
