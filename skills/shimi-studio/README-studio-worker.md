# ShimiStudio — מפעל ייצור וידאו

מערכת ייצור וידאו מקומית מבוססת AI המקבלת משימות רינדור מרחוק משרת Base44, מייצרת אותן על גבי המחשב האישי בעזרת ComfyUI, ומדווחת על הנתונים והתוצרים בחזרה לשרת.

---

## 📌 דרישות מערכת
- **מערכת הפעלה**: Windows 10/11 או Linux (64-bit)
- **פייתון**: Python 3.10 ומעלה
- **כרטיס מסך (GPU)**: מומלץ כרטיס NVIDIA עם לפחות 8GB VRAM (תמיכה ב-CUDA). ניתן להריץ גם על מעבד (CPU), אך הרינדור יהיה איטי יותר.
- **שטח דיסק פנוי**: לפחות 20GB (עבור מודלים של Wan 2.1 ו-LTX-Video).
- **חיבור אינטרנט**: לצורך הוריד מודלים וחיבור לשרת הפיקוד.

---

## ⚙️ התקנה (Setup)

1. פתח חלון טרמינל / PowerShell בתיקיית הפרויקט.
2. עדכן את הקובץ `config.json` והכנס את ה-`worker_token` שקיבלת משרת Base44.
3. הרץ את סקריפט ההתקנה האוטומטי:

```bash
python setup.py
```

### מה סקריפט ההתקנה מבצע?
- בודק את גרסת ה-Python במערכת (דורש 3.10+).
- מזהה אם קיים כרטיס מסך NVIDIA (CUDA).
- יוצר סביבה וירטואלית (`.venv`).
- מתקין את ComfyUI והרכיבים הנדרשים.
- מתקין Custom Nodes: `ComfyUI-VideoHelperSuite` ו-`ComfyUI-AnimateDiff-Evolved`.
- מוריד אוטומטית את כל המודלים הנדרשים למקומם הנכון:
  - **Wan 2.1 1.3B Diffusion Model** → `ComfyUI/models/diffusion_models/`
  - **Wan 2.1 VAE** → `ComfyUI/models/vae/`
  - **umt5-xxl Text Encoder** → `ComfyUI/models/text_encoders/`
  - **LTX-Video 2B Checkpoint** → `ComfyUI/models/checkpoints/`
  - **LTX Text Encoder** → `ComfyUI/models/text_encoders/`

## 🚀 הפעלה (Run)

לאחר סיום ההתקנה, ניתן להפעיל את ה-Worker בדרכים הבאות:

### Windows (PowerShell):
```powershell
.\start.ps1
```

### Linux / Mac:
```bash
./start.sh
```

## 🔄 איך המערכת עובדת?

1. **שרת הפיקוד (Base44)** מקבל בקשות ליצירת וידאו ויוצר רשומות משימה (`RenderJob`).
2. **ה-PC המקומי (Worker)** פונה לשרת Base44 בלולאה קבועה (מדי 10 שניות) ושואל אם יש משימות ממתינות.
3. **עיבוד המשימה**:
   - ה-Worker מעדכן את סטטוס המשימה ל-`in_progress`.
   - טוען את תבנית ה-Workflow המתאימה (`wan21_t2v` או `ltx_t2v`).
   - משתיל את הפרמטרים (הנחיה טקסטואלית, מידות, צעדים, קצב פריימים וכו').
   - שולח את המשימה ל-ComfyUI המקומי וממתין לסיום הרינדור.
4. **עלאה והחזרת תוצאה**:
   - ה-Worker מוריד את קובץ הוידאו המוכן מ-ComfyUI.
   - מעלה את קובץ הוידאו לשרת האחסון `0x0.st`.
   - מדווח לשרת Base44 על סיום המשימה (`completed`) בצירוף הקישור לוידאו המוכן.
   - במקרה של שגיאה, מדווח על סטטוס `failed` בצרוף הודעת השגיאה.

## 🛠️ פתרון בעיות נפוצות

### 1. שגיאת זיכרון (Out of Memory / CUDA OOM)
- ודא שאין תוכנות כבדות אחרות המשתמשות ב-GPU.
- במידת הצורך, ניתן להפחית את רזולוציית הוידאו (`width`, `height`) או מספר הפריימים במשימה.

### 2. ה-Worker אינו מצליח להתחבר לשרת Base44
- ודא שה-`worker_token` בקובץ `config.json` תקין ומעודכן.
- ודא שכתובת ה-`base44_url` נגישה מהמחשב שלך.

### 3. ComfyUI אינו עולה
- בדוק אם פורט 8188 פנוי במחשב שלך.
- נסה להריץ את ה-`setup.py` שוב לוודא שכל התלויות והרכיבים הותקנו כראוי.

### 4. כרטיס NVIDIA אינו מזוהה
- ודא שדרייבר כרטיס המסך (NVIDIA Driver) מעודכן במחשב.
- הרץ את הפקודה `nvidia-smi` בטרמינל לוודא שהמערכת מזהה את ה-GPU.
