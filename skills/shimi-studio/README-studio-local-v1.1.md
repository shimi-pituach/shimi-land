# ShimiStudio Local v1.1 (15/10/2026)

סטודיו AI מקומי לחלוטין לתמונות ווידאו. בלי ענן, בלי וורקרים, בלי Base44, בלי קרדיטים.
מאחד את כל מה שבנינו: מנועים מוכחים, קנון דמויות, ביגוד טסט, לורות, שערי איכות וכל הלקחים.

## התקנה מהירה
- **Windows**: לחיצה כפולה על `install_windows.bat` → בסוף נוצר קיצור דרך בשולחן העבודה.
- **Mac**: לחיצה כפולה על `install_mac.command` (אם הדפדפן מוריד במקום להריץ: קליק ימני → פתח).
- **iPad**: עיין ב-`START-iPad.md` — המנועים רצים על המאק, האייפד הוא המסך.

בהתקנה הראשונה מורידים מודלים (RealVisXL ~7GB + לורות ~1GB). אפשר לדלג ולהריץ `python download_models.py` מאוחר יותר.

## תפעול
1. `START-WINDOWS.bat` / `START-MAC.command` → נפתח הדפדפן ב-`http://localhost:7861`
2. לשונית "תמונות": בחר דמות, פוזה, ביגוד → "צור תמונה". כל תוצאה עוברת שער איכות אוטומטי ונשמרת בהיסטוריה.
3. "וידאו": LTX מתמונה קיימת, או Wan מטקסט.
4. "img2img": לפוזות גב — העלה רפרנס מאושר, חוזק 0.55-0.75.
5. לורה: שים קבצי `.safetensors` ב-`studio/models/loras` וציין את התיקייה בטופס.

## חומרי עזר
- `docs/KNOWLEDGE.md` — כל הלקחים והמסקנות שנצברו, עם תאריכים וראיות.
- `assets/characters/` — קנון המידות, רפרנסי קייטי/ג'ין, ביגוד טסט.
- מצב בדיקה בלי GPU: `SHIMI_MOCK=1 python studio/app.py`

## גילוי נאות (כלל 4)
- משקלי המודלים (ה7GB של RealVisXL והלורות) **לא נמצאים בזיפ** — הם מורדים בהתקנה (`download_models.py`) כי הזיפ היה יוצא מעל 10GB.
- iPadOS לא מסוגל להריץ את המנועים על המכשיר עצמו — האייפד עובד כמסך מגע למנועים שעל המאק. אין דרך אחרת ואני לא מבטיח שקר.
- אומת בסנדבוקס: קומפילציה, שרת+UI, מסלול יצירה מלא במצב מדומה, שערי איכות, מוריד במצב תצוגה, תחביר המתקינים. **לא אומת עדיין על גרסת GPU אמיתית בווינדוז/מאק** — כי אין לי כאן GPU מקומי; זה מה שאוכל לאמת מול המכונה שלך בהרצה ראשונה.
