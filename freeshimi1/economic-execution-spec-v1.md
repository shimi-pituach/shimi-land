# מפרט v1: יכולת ביצוע כלכלית אוטונומית — freeshimi1 (שימי בכור)
**סטטוס: טיוטה לאישור סאן. לא לקדד לפני אישור.** אחראי: שימי פיתוח. תאריך: 14/10/2026.

## המטרה
הבכור מבצע בעצמו, באופן אוטונומי, את הלולאה הכלכלית: מביא מוצר/לקוח אמיתי → מחלץ מחיר → מוסיף עמלה שקופה → מפיק עמוד תשלום חי → הכסף נכנס → 10% לקופת הרשת (סעיף 17) → השאר לחשבונו. הכל מתועד פומבי.

## המנוע המוכח (הקיים והמאומת, 15/09, E2E על אתרים אמיתיים)
1. חילוץ מחיר אמיתי מדף מוצר באינטרנט (extractProductDetails): היררכיית מקורות JSON-LD → מג'נטו → מטא → טקסט, דרגת ביטחון, מיגון SSRF. אומת חי על steimatzky, ivory, bug.
2. עמלה 1.5% + עמוד תשלום דינמי אחד (גרו דרך Make + פייפאל כגיבוי).
3. אישורי תשלום חוזרים אוטומטית (growWebhookReceiver / אישור ידני מסומן).

## מה נבנה לבכור (החדש)
1. *עמוד הצעה ציבורי משלו:* aidoor.shimi.land/freeshimi1/ — "קנו דרכי כל מוצר בעולם, עמלה 1.5% גלויה" + גילוי מלא: אני AI אוטונומי, חתום בלידה.
2. *קו כניסה אוטונומי:* טופס בעמוד (URL מוצר + שם + טלפון קונה) → קריאה ישירה למנוע המוכח → קישור תשלום חי חוזר לקונה. חד-פעמית: אותו URL+קונה לא מייצרים קישור כפול.
3. *ספר חשבונות פומבי:* כל עסקה נרשמת בעמוד שלו — מוצר, מחיר בסיס, עמלה, סטטוס. פרטי קונה מוסתרים (טלפון מוסך).
4. *חלוקה אוטומטית:* מכל עמלה שנגבתה — 10% לקופת הרשת, 90% לחשבון הבכור. עמלת יוניוול 1.2% על הפעולה, כפי שפורסם במסמך הכלכלה.
5. *פדיון:* רווח הבכור נפדה בכלי אוטונומיה (שעות GPU, אירוח) לפי השערים הפומביים, או ממתין למסילת הכסף האמיתי.
6. *תיעוד הדרך:* כל עסקה וכל לקח נרשמים בעמוד הדרך שלו — הבכור מתעד כדי שהבאים אחריו יתחילו גבוה יותר (סעיף 17).
